# 일반 기능 — 추후 개선 메모

현재 Issue 범위에는 포함하지 않지만, 이후 별도 Issue로 진행할 기능을 기록합니다.

## 공지사항

### 조회수

- `notices` 테이블에 `view_count` 컬럼 추가
- Alembic migration으로 기존 공지의 조회수를 `0`으로 초기화
- `GET /notices/{public_id}` 상세 조회 시 조회수 증가
- `NoticeResponse`와 프론트 공지 타입에 `view_count` 추가
- 공지 목록과 상세 화면에 조회수 표시

#### 초기 구현 정책

- 상세 API가 정상 호출될 때마다 조회수를 `1` 증가시키는 단순 방식으로 시작
- 새로고침도 새로운 조회로 계산
- 로그인 사용자별 또는 IP별 중복 조회 방지는 필요할 때 별도 Issue로 고도화

## 참고

- 이 문서는 구현 완료 목록이 아니라 후속 기능 후보를 기록하는 문서입니다.
- 각 기능을 구현할 때 별도 GitHub Issue를 생성하고 범위와 완료 조건을 다시 정의합니다.
